# Project Rules

- Root rules: `AGENTS.md`.
- Frontend: `frontend/`; Android wrapper: `frontend/android/`.
- Backend: `backend/`.
- Frontend build: `npm --prefix frontend run build`.
- Backend tests: `npm --prefix backend test`.
- APK output: `frontend/android/app/build/outputs/apk/debug/app-debug.apk`.
- Do not fabricate parser values or expose secrets.
